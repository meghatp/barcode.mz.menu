# BARCODE Cocktail Menu

A responsive, animated cocktail menu built with plain HTML, CSS and JavaScript.

## Run it
Open `index.html` in a browser. For the best local development experience, use VS Code with the Live Server extension.

## Customize the 8 cocktails
Open `js/menu.js`. Each cocktail has:
- `name`: displayed cocktail name
- `price`: displayed price (include the currency, e.g. `AED 48`)
- `note`: short flavour / style line
- `image`: path to its image

Replace the SVG files in `assets/images/` with your own photos, or add new image files there and update the matching `image` path in `js/menu.js`. Recommended photo shape: portrait, around 4:5.

## Replace the logo
Replace `assets/barcode-logo.jpg` with your final logo file and update the image path in `index.html` if you use a different filename.

## Brand colours
Edit the CSS variables at the top of `css/styles.css` to adjust black, gold and white tones.
